# climat_energy

Локальный генератор коммерческого предложения (КП) для инженерных систем.

## Быстрый запуск
1. Откройте `index.html` двойным кликом (без сервера).
2. Заполните поля слева.
3. Используйте:
   - `📄 Мгновенный экспорт PDF`
   - `⬇️ Экспорт JSON` / `⬆️ Импорт JSON`
   - автосохранение черновика в браузере.
