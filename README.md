# climat_energy

Теперь основной вариант — **desktop-программа на Python**, без Edge/Chrome.

## Запуск без браузера
1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите:
   ```bash
   python desktop_kp_generator.py
   ```

## Мгновенный PDF
- Кнопка `Экспорт PDF (сразу)` сразу формирует PDF-файл в папке программы.
- PDF векторный (текст остаётся текстом, не картинка).
- Для длинных КП реализована аккуратная пагинация, чтобы секции не рвались «кусочками».

## Сборка EXE (Windows)
1. Запустите `build_exe_windows.bat`.
2. Готовый файл: `dist\KP_Generator.exe`.

## Старые веб-файлы
- `index.html/index.js` и `.cmd` оставлены для обратной совместимости, но рекомендуется desktop-версия.
