# climat_energy

Локальный генератор коммерческого предложения (КП) для инженерных систем.

## Быстрый запуск
### Windows (рекомендуется)
1. Нажмите на файл `Запуск КП генератора.cmd`.
2. Генератор откроется в режиме приложения (без вкладок и адресной строки).

### Универсально
1. Откройте `index.html` двойным кликом.

## Возможности
- `📄 Экспорт PDF`
- `⬇️ Экспорт JSON` / `⬆️ Импорт JSON`
- автосохранение черновика в браузерном хранилище


### Если .cmd открыл пустое окно браузера
- Проверьте, что рядом с `.cmd` лежит файл `index.html`.
- Убедитесь, что установлен Edge или Chrome.
- В крайнем случае откройте `index.html` напрямую.
