# КП — Генератор коммерческих предложений | Climat Energy

Десктопное Electron-приложение для создания и печати коммерческих предложений.

## Запуск (режим разработки)

```bash
npm install
npm start
```

## Сборка .exe для Windows

### На Windows:
```bash
npm install
npm run build
```
Готовые файлы появятся в папке `dist/`.

### Доступные варианты сборки:
- `npm run build` — portable .exe + NSIS installer
- `npm run build:portable` — только portable .exe (один файл)
- `npm run build:installer` — только NSIS установщик

## Структура проекта

```
├── main.js          — Electron главный процесс
├── preload.js       — безопасный мост Electron
├── index.html       — приложение (HTML/CSS/JS)
├── assets/
│   └── icon.ico     — иконка приложения
└── package.json     — конфигурация проекта
```

## Возможности приложения

- 5 разделов услуг: Отопление, Вентиляция, Кондиционирование, Видеонаблюдение, Пожарная сигнализация
- Реквизиты компании и клиента
- Расчёт итогов с НДС / без НДС
- Печать и сохранение PDF через `Ctrl+P`
- Профессиональное оформление документа
